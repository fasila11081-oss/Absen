Koneksi Realtime Online (Google Apps Script & Google Sites)

Terhubung otomatis ke endpoint Google Apps Script Anda untuk sinkronisasi realtime presensi, Salat Subuh, & data 142 siswa.

Catatan Akses: URL berakhiran /dev aktif langsung untuk akun Google pemilik script. Jika dipakai di banyak HP guru/orang tua tanpa login Google, Anda juga dapat memakai URL deployment /exec (akses: Siapa saja / Anyone).

Kode Lengkap Google Apps Script (Presensi_Realtime + Data_Siswa):
  1. Pastikan di editor Apps Script Anda sudah terpasang kode penerima doGet(e) & doPost(e) (klik Salin Kode Apps Script jika ingin memperbarui).
  2. Klik tombol Kirim 142 Siswa ke Sheet di tab Data 142 Siswa untuk mengisi sheet Data_Siswa secara otomatis.
  3. Setiap hasil scan QR, presensi H/S/I/A, dan Salat Subuh akan langsung masuk realtime ke sheet Presensi_Realtime.
